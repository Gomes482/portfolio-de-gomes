CASE DE DESENVOLVIMENTO

Sobre o Caderno de Pedidos

Um projeto de digitalização de uma rotina real de organização de vendas.

O que foi desenvolvido?

Aplicação web em Python e Flask para cadastro e acompanhamento de pedidos, itens, valores, entradas, parcelas, recebimentos e vencimentos, com interface responsiva para computador e celular.

Backend originalPython · Flask
Dados da aplicação originalBanco SQL
InterfaceWeb responsiva
Proteção da demonstração: esta página é um arquivo estático separado da aplicação operacional. Não faz login, não se conecta ao banco original, não expõe clientes reais e não permite cadastrar, editar, excluir, exportar ou enviar mensagens.
